仙剑奇侠传 DOS 资源包生成器

选择安装目录后，本页会自动验证、转换并生成 Cardputer ADV 与 Xiaomiao 共用的完整 TF 资源包。游戏文件不会上传。

请用当前版 Chrome 或 Edge，并通过 HTTPS 或 localhost 打开本页面。

1 选择《仙剑奇侠传》DOS 原版安装目录 等待选择

必须是繁体中文 DOS 原版；不支持 Win95/98 版、柔情篇或混合修改过的资源。

2 验证 DOS 原版文件 等待上一步

检查必需文件、MKF 表、DOS YJ1、游戏数据表及媒体结构；不会用固定的游戏文件 SHA-256 限定 DOS 版本。

3 下载并验证字体资源 等待上一步

下载仓库提供的 FONT10 子集，并验证 ZIP、SHA-256、CRC32 和字形数据。

4 生成并下载完整 TF 资源包 等待上一步

输出 PALSET.BIN、manifest、pal_core/full.pak 和 b00.pak～b14.pak。
